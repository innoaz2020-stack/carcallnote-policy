carCallnote (정비수첩) 개인정보처리방침

시행일자: 2026년 11월 11일 | 문서 버전: v1.1 (정식 출시본)

🔒 핵심 원칙: 사장님의 영업·고객 자료는 개발자 서버로 절대 수집·전송하지 않습니다 (Zero-Customer-Data Policy)

carCallnote (정비수첩)는 별도 회원가입이나 중앙 서버 없이 동작하는 로컬 중심 애플리케이션입니다. 사용자가 앱에 입력하는 고객 이름, 전화번호, 차량번호(번호판), 차종, 정비 방문·예약 이력, 정비 금액, 메모, 차량/정비 사진은 오직 사용자의 스마트폰 내부 저장소(및 사용자가 직접 동의·지정한 본인 개인 백업 경로)에만 보관되며, 개발자 또는 제3자의 서버로 단 1바이트도 수집·전송되지 않습니다.

1. 개인정보 및 영업자료의 보관 위치와 백업 방식

  • 회원가입 없음: 본 앱은 별도의 서버 계정 생성이나 로그인을 요구하지 않습니다.
  • 기기 내 단독 보관: 모든 고객·차량·정비·예약 기록(carcallnote.db)과 사진(files/photos/)은 사용자 단말기의 앱 전용 내부 저장소에만 저장되며, 사진 저장 시 위치 정보 등 원본 EXIF 메타데이터는 재인코딩 과정에서 자동 제거됩니다.
  • 수동 암호화 전체 백업(.ccnbak): 기기 변경·분실 대비 전체 백업 시 사용자가 직접 입력한 암호(8자 이상)를 기반으로 PBKDF2-HMAC-SHA256(600,000회 반복) 및 4MB 청크 단위 AES-256-GCM 방식으로 강력하게 암호화된 백업 파일이 생성됩니다.
  • 고객 동의 기반 본인 Google 드라이브 일일 텍스트 백업(.json): 사용자가 앱 내 안내를 확인하고 직접 동의 체크 및 파일 연결을 완료한 경우에 한하여, 사진을 제외한 복구용 텍스트 데이터(고객·전화번호·차량·정비·예약·메모)가 사용자 본인 계정의 Google 드라이브(SAF 문서 URI)에 비상 복구용 JSON 텍스트 파일로 저장됩니다. 개발자는 해당 드라이브나 파일에 일절 접근할 수 없으며, 암호화 보관을 원할 경우 언제든 자동 업로드를 끄고 .ccnbak 암호화 백업만 단독 사용할 수 있습니다.
  • Android 운영체제 기본 기기 백업: 기기 변경 시 복원 편의를 위해 운영체제 기본 앱 데이터 백업에 텍스트 데이터베이스(carcallnote.db)가 포함될 수 있으며, 사진 폴더(files/photos/)·임시 백업·진단 로그는 동기화 대상에서 제외(data_extraction_rules.xml)됩니다.

2. 기기 권한 사용 안내 및 최소 접근 원칙

본 앱은 통화기록 열람(READ_CALL_LOG), 주소록 전체 읽기(READ_CONTACTS), 발신 통화 가로채기(PROCESS_OUTGOING_CALLS) 권한을 일절 요청하거나 포함하지 않습니다.

3. 비식별 작동·오류 카운터 진단 (고객 데이터 원천 배제)

앱 내 [설정 > 작동 확인 · 에러 카운터 진단] 기능은 고객명·차량번호·전화번호 등 영업 자료를 일절 포함하지 않으며, 기기 내 정규식 마스킹 필터(scrubSensitiveText)를 통해 숫자열과 식별 패턴을 제거한 비식별 카운터(수신팝업·OCR·백업 작동 횟수 및 비식별 오류 코드)만 기기 내부에 기록합니다. 백그라운드에서 외부 분석 서버로 자동 전송하는 코드는 존재하지 않습니다.

4. 데이터의 파기 및 이용자 권리

  • 사용자는 언제든지 앱 내에서 개별 고객, 차량, 정비 방문 내역, 예약, 사진을 즉시 수정하거나 영구 삭제할 수 있습니다.
  • 정기구독을 해지하거나 무료 체험이 종료되더라도 기기에 이미 저장된 모든 데이터는 삭제되지 않고 그대로 열람·백업할 수 있습니다.
  • 앱을 스마트폰에서 삭제(언인스톨)하면 앱 내부 저장소에 보관된 모든 데이터베이스와 사진은 운영체제에 의해 즉시 완전히 파기됩니다(단, 사용자가 직접 외부 폴더나 본인 Google 드라이브에 내보낸 백업 파일은 사용자가 직접 삭제할 수 있습니다).

5. 서비스 제공 환경 및 운영체제·제조사 정책 변동 유의사항

전화 수신 시 차량·정비 요약 팝업 표시 기능은 Android 운영체제, 단말기 제조사(삼성 갤럭시 One UI 등) 및 앱 마켓의 시스템 권한·통화 화면 정책 범위 내에서 제공됩니다. 향후 운영체제 업데이트, 단말기 제조사 보안 정책 또는 플랫폼 정책 변경으로 시스템 권한이나 화면 표시가 제한·차단될 경우 부득이하게 해당 팝업 기능의 표시 방식이 변경되거나 제공이 제한·중단될 수 있습니다(단, 기기 내에 저장된 고객·차량·정비 기록 조회, 4자리 통합 검색 및 백업·복원 기능은 그대로 유지되며, 이용자는 언제든 Google Play에서 정기구독을 해지할 수 있습니다).
